# 🐢 Tortle of love 💖

> Here, you can find all the source-code of a little python program for show your love to the love of your life 🔥


## Start the py script:
- Place the `main.py` file where you want.
- Open a command prompt into the current folder.
- Type `python main.py`. No dependencies requiered 😉
